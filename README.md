# Two Good Co - Frontend

A responsive, animated frontend web experience built to showcase modern web design practices. The project features smooth scrolling and dynamic visual elements.

## 🚀 Live Demo

**[View the Live Site](https://saad-2006.github.io/Two-Good-Co/)**

## ✨ Features

*   **Smooth Scrolling:** Integrated customized smooth scrolling for a premium user experience.
*   **Dynamic Animations:** Custom CSS and JavaScript animations triggered on scroll and user interaction.
*   **Responsive Design:** Fully responsive layout optimized for desktop, tablet, and mobile displays.
*   **Modern UI:** Clean, minimalist interface focusing on typography and imagery.

## 🛠️ Tech Stack

*   **HTML5** 
*   **CSS3**
*   **Vanilla JavaScript**
*   **Locomotive Scroll** (for smooth scroll hijacking and parallax effects)
*   **Remix Icon** (for scalable vector iconography)

## 💻 Local Installation

To run this project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone [https://github.com/Saad-2006/Two-Good-Co.git](https://github.com/Saad-2006/Two-Good-Co.git)

```

2. Navigate to the project directory:
```bash
cd Two-Good-Co

```
3. Open the `index.html` file in your browser, or use a local development server like VS Code's Live Server extension.
